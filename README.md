# Huddle - Sports Social Networking & Forum Platform
Our team designed and implemented a hub for all things hockey. Huddle is a sports-focused discussion forum platform that allows its users to closely follow their favorite hockey teams, as well as read and post about different teams in the league. Users are also able to keep track of games through schedules of upcoming matches, look up player statistics and overall team standings.

### Features

- **Team Following:** Follow and discuss favorite hockey teams
- **Discussion Forums:** Read and post about different teams in the league
- **Game Schedules:** Track upcoming matches and game times
- **Player Statistics:** Look up individual player stats
- **Team Standings:** View overall league standings

### Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Server:** Apache (XAMPP)
- **Testing:** Jest (JavaScript), PHPUnit (PHP)

### Installation

**Prerequisites:**
- XAMPP 8.1.12-0

**Setup:**
1. Install XAMPP and start the following servers:
   - MySQL Database
   - ProFTPD
   - Apache Web Server

2. Import the project files (`.php`, `.sql`, `.js`, `.css`, Jest tests, PHPUnit tests) into your `XAMPP/xamppfiles/htdocs` folder

3. Initialize the database:
   - Navigate to `http://localhost/phpmyadmin/` in your browser
   - Import the `huddledatabase.sql` file

4. Access the application through your local server
